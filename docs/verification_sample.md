# Independent alignment verification

**Status: protocol only. No independent alignment correctness estimate has been measured here.**

## Method
1. Freeze the realignment script and algorithm version.
2. Use deterministic, documented random sampling; stratify/oversample repaired, unchanged, repeated-text, seven discourse categories, essays and beginning/middle/end locations as appropriate.
3. Two reviewers independently decide the intended span boundaries **without seeing the algorithm-selected offsets**.
4. Adjudicate disagreements; record reviewer agreement and whether exact start and end are correct.
5. Report both raw counts and a confidence interval; account for sampling weights when oversampling difficult cases.
6. Thirty hand-checked cases are good for debugging but **not** evidence for near-100% accuracy. Plan a larger representative sample (e.g. 300–400) before claiming a population rate.
7. Keep essay text and identifiable fields out of public GitHub; log non-identifying segment IDs.
